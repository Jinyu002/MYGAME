# ADR 0003：按原作时序研究重构行动特写

日期：2026-10-25。范围：Demo v0.3 的演出，战斗规则保持独立。

## 依据与边界

本地资料证据见 `research/REFERENCE_RESEARCH.md`：`study/scripts/timescript/melee.times:3–17,20–45,51–94` 包含镜头、HUD、临时站位、漂移与归还变换；`melee_crit.times:7–15,45,51–53` 区分暴击；`ranged.times:45,58–64` 区分远程；`friendly_skill.times:19–26,39–55` 区分支援。

0.085等值来自参考配置，但缺少宿主执行代码，不能宣称已还原原版总时长、骨骼动画或投影数学。本实现独立编写，使用快速切入攻击姿态、持势漂移、统一恢复表达原作的行动特写语言。没有复制参考时序文件。

## 实现

- `shot_director.gd` 是现行导演；旧 `presentation_director.gd` 暂留作初版对照，不被应用引用。
- `content/presentation.json` 配置近战、远程、支援、暴击、换位，以及技能姿态映射。技能规则不引用素材路径。
- 表现临时站位独立于战斗阵位；群体目标增加间距并降低放大倍率。敌方行动反向构图。
- 背景屏幕采样模糊、去色、压暗，发生在特写角色层之下；HUD独立CanvasLayer，底部信息随特写淡出，弹字仍清晰。
- 七种新增技能姿态从原图集只读提取，资源总数38。原库未改变。盾震、突进、连射、破势、灯火、掩护及弩手近战有独立映射。
- 命中仅发送一次，逻辑不等待特效再随机结算；命中冲击、治疗圆环、闪避线由程序绘制。暴击有更强去色、镜头倾斜和指数衰减震动。
- 特效时钟由导演控制，暂停不推进；变速同步时间轴与特效。skip、重启、看门狗均清理效果、背景滤镜、角色临时位置及相机。

## 验证与限制

新增 `tests/run_presentation.gd`：六类已结算合成记录，44项检查，覆盖自然结束、一次性命中/结束、姿态、特效暂停、镜头与滤镜复位。合成记录用于表现测试，不作为规则正确性证据；规则另有956项检查和100种子模拟。图形运行保存六张真实截图，headless不作为分辨率证据。

仍缺完整Spine待机、独立受击/死亡序列、武器接触点与原版音频环境。当前复现的是主要演出结构，不能称一比一复刻原版。
