# ADR 0004：反馈生命周期与暴击修饰

日期：2026-10-26，已采用。依据：CURRENT_PRESENTATION_AUDIT中的暂停/死亡实测，以及用户本轮UI、近战和必暴体验要求。

保留规则输出ActionRecord、导演单impact和完成屏障。main显式登记弹字/死亡Tween；暂停、倍速、结束、重试管理这一组反馈，同时控制ActorView与音频。选择局部时钟控制以保留菜单和MCP辅助运行，未采用原型的全局SceneTree暂停。恢复可见性及阵位以record.after为准。

暴击为melee/ranged/support基础profile的效果修饰，不覆盖基础距离。距离允许按技能配置；这是当前静态姿态的小范围校准，不替代未来美术锚点和包围盒镜头。HUD明确标记淡出控件，弹字和菜单不受位置阈值误伤。

resolve使用现有数据驱动概率crit=10000及可选sure_hit。后者仅影响命中率，仍消费正常指令、次数、伤害与事件流程；必暴预览包含暴击倍率。以100种子和实际图形演出验证，暂作体验技能而非最终平衡承诺。

风险与后续：显式反馈注册要求所有新反馈沿用feedback_tween；未注册Tween不能宣称暂停正确。更多技能时需再次评估技能栏，当前只验证3/4个技能。多段伤害、复杂动画管线仍延后。完整测试、限制和复现见 research/PRESENTATION_ITERATION_04.md。
