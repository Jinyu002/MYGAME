# ADR 0002：本地可测试切片实施调整

日期：2026-10-25；状态：已实现并进行自动/渲染验证。

1. 用户明确授权study美术用于Demo，覆盖v0.1“先自行占位”的安排。提取31项PNG副本，记录原路径、哈希和操作；仅在game写出。atlas只读用于解包美术，不复制非美术业务配置。授权记录不伪称第三方公开发行许可证。
2. 原作combat是骨骼部件图集；当前使用完整defend姿态作待机，独立attack姿态作攻击。先交付可测试流程，再评估骨骼/分层动画；不将散装骨骼部件拼成错误立绘，也不引入运行库依赖。
3. 小规模定义采用独立JSON，而非立即创建Resource类。所有数值为整数，载入时递归规范化，防止JSON float与阵位int精确成员判断不一致。战斗状态独立Dictionary深拷贝，表现不持有可修改规则引用。内容量扩大且编辑器资源工作流有实际收益时再迁移。
4. 当前应用入口为seed/battle_id与预设参与者定义；已输出BattleResult，尚未实现完整外部BattleRequest参与者快照导入。世界接入时再补，不创建无调用者的空模块。
5. Director统一Tween序列与Camera2D写入，显式区分并行准备/顺序接触/并行恢复，加入skip与5秒看门狗。不是复刻原作timescript执行器。
6. 环境自行用2D几何绘制；study本批未包含完整场景背景。参考图标用于测试技能按钮，语义以本项目中文说明为准，正式版必须替换匹配图标。
7. 目标选择经按钮事件进入同一规则命令接口；暂停取消尚未执行的AI决策token，重试改变battle_id/generation，避免旧计时器作用于新战斗。

限制：尚无原创美术定稿、完整骨骼待机/受击帧、投射物/武器接触点、多目标自适应镜头、音量滑杆、可展开战报、外部参与者输入或独立打包exe。现有合法性/状态/胜负/资源替换和演出恢复是真实功能，不以未来TODO代替。
