# 战斗 Demo 游戏设计 v0.1

状态：可实施设计，尚未实现/平衡验证。所有以下名称、规则和数值是本项目独立决定，不是原作机制结论。角色为功能代号，不锁定世界观。

## 体验与范围

玩家控制四人队伍，在前后阵位约束下决定集火、打断、援护和换位。核心体验是“行动选择可读，命中有重量，下一步策略清晰”。标准一战目标 4–7 轮、5–8 分钟（体验目标，待实测），不是压力养成或刷装备演示。

当前完整闭环：开始界面 → 预设遭遇 → 战斗 → 胜利/失败/撤退结果 → 重试/返回。含 4 名英雄、3 种敌人组成的 4 敌遭遇、12 个职业技能、通用换位/防御、状态、AI、完整镜头与 UI、音量/震动设置。不做探索、成长、掉落背包、永久死亡、存档、压力、死亡之门、尸体、召唤、多格大型敌人。结果保留上层可消费的状态数据，但不产生虚假的经济奖励。

## 阵位与行动

- 双方各最多四个存活角色，1 为最前排。默认画面左方英雄从左至右为 4/3/2/1，右方敌人为 1/2/3/4。
- 每轮开始，对存活角色生成 `速度 + 随机整数[0,3]`，降序；平手随机键排序，再以稳定 entity_id 保底。种子固定时结果相同，不偏向任何一方。
- 每个角色每轮一次行动。速度变化从下一轮生效；位移不增减本轮行动次数。死亡从待行动队列移除。
- 选择技能 → 高亮合法目标 → 显示命中、伤害区间、效果 → 确认。确认前可取消；提交后禁用重复输入。无效命令不耗行动、不消耗随机数。
- 通用换位：与相邻存活友方交换，消耗行动；边缘只有一个方向。强制后退：沿己方队列向后移一位，交换经过者；已在末位则无位移。死亡后队伍向前压缩，生还者次序不变。
- 通用防御：从任意阵位使用，赋予自身“坚守”，消耗行动。无合法攻击目标也能防御/换位，绝不锁死。

## 数值与结算

所有概率以整数基点（10000=100%）存储。命中率 `clamp(技能命中-目标闪避, 500, 10000)`；UI 显示真实最终概率，没有隐藏命中补偿。友方治疗/援护必定成功，不做命中判定。

伤害：先在技能整数区间均匀取值；命中后按技能暴击率独立抽样，暴击为基础伤害×1.5；护甲百分比减伤（上限 60%），坚守再减伤 35%；最终统一向下取整，命中的直接伤害至少 1。效果型零伤技能不强制产生 1 点伤害。治疗不暴击，不能超过最大生命或复活。持续伤害不暴击且忽略护甲/坚守。

每个行动按目标阵位升序处理：验证命令 → 记录使用次数 → 命中 → 暴击/伤害 → 致死标记 → 存活目标附加效果 → 位移 → 一次性压缩双方阵列 → 判定胜负。多目标在行动开始锁定 entity_id，死亡压缩不能改变本次目标集合。基础伤害未命中则附加效果不触发。

状态应用率 `clamp(效果基础概率-目标对应抗性,0,10000)`，每个效果分别抽样。被免疫显示“免疫”，成功/抵抗明确反馈。规则事件序列保留实际生效值、来源与目标。

| 状态 | 规则 |
|---|---|
| 流血 | 每次该角色行动开始扣 3 HP，共触发 2 次。再次施加刷新剩余次数至 max(当前,2)，不叠加伤害；击倒后不执行行动 |
| 眩晕 | 行动开始在流血后检查，消耗并跳过一次行动；不可堆叠。解除时获得抗眩晕 100%，持续至其下一次行动结束，避免连续控制 |
| 坚守 | 直接伤害×0.65，持续至施加者下一次行动开始（先移除再处理流血）；不叠层，可刷新 |
| 破甲 | 护甲减 20 个百分点，下限 0；持续到目标完成两次行动（被晕跳过也计次）；重复刷新不叠层 |

行动开始顺序：清除到期坚守 → 流血结算/扣次数 → 死亡及胜负判定 → 眩晕判定 → 请求行动。行动结束扣破甲持续时间，清除到期抗眩晕。状态应用发生于行动内部，计时按“受影响者之后的行动结束/开始”计数，施加当下不额外扣减。

## AI 与结束

AI 只从规则返回的合法命令中选：可击倒目标+30分、有效新状态+10、基础伤害期望值加分；同分用专用 AI 随机流抽样。低于30% HP的护卫首次防御优先，否则不连续防御；无攻击动作时优先换位以接近可攻击阵位，无法改善才防御。与战斗随机流分离，避免 UI 预览或 AI 评分改变结算随机数。

每个原子动作/回合开始效果组后检测：双方都无存活为平局，仅敌方为空为胜利，仅己方为空为失败。致死后先播完整结果再显示结算。撤退通过暂停菜单显式确认，生成撤退结果；重试创建新 battle_id 并清理旧演出。防止拖延：50轮后平局“僵持结束”，在45轮开始提示。结果包含胜负、轮数、存活/HP摘要和事件日志，不直接改世界状态。

## 演出与 UI

普通攻击预算约 0.95–1.35 秒：准备0.12–0.20、接触0.10–0.18、受击强调0.04–0.07、持势0.30–0.45、复位0.25–0.35。暴击增加强调与声音层，不机械延长全部片段。这些是原型起点，不能作为完成验收。

角色在阵位与演出站位之间过渡，镜头按攻击者与所有目标包围盒适配；放大上限1.25。打击帧同步受击姿态、短闪、声音与数字；未命中使用闪避/擦过，不播放命中震动。UI 保留生命与回合信息，暂时禁用操作并降低技能栏强调，避免演出中全屏失去信息。可关闭震动/闪光。

4K：顶部0–240为轮次/行动队列；舞台240–1512；下部1512–2160为状态、技能、目标预览和可折叠日志。脚底基线约1370；常规人形有效高度720–900；左右安全边界至少96。技能按钮144×144，正文42、辅助36、标题64、伤害数字88逻辑像素；QHD缩放2/3后仍可读。战斗布局由容器和锚点维护，不能用纹理空白区定位。

输入：鼠标、1–3职业技能、M换位、G防御、Esc取消/暂停；按键提示与禁用原因明确。目标用边框+形状+文字辅助，不仅靠颜色。快捷键不得绕过确认和合法性检查。中文字体另做许可与缺字验证。

## 完成标准

完整一战胜/负/撤退可重复运行；所有技能和状态有可理解反馈；数据测试、异常恢复、两种重点分辨率、资源替换和性能检查通过。合法占位完成的是功能/演出切片，正式美术品质需原创资源接入后的独立验收。
